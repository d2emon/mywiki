# 🕳️ ЧЁРНЫЙ РЫНОК

> _«То, что не продаётся — не существует.  
> То, что продаётся — уже за вами следят.»_

## 1. Как находят чёрный рынок

Никогда напрямую. Только через:

- криминальные контакты    
- слухи в барах / доках
- посредников
- случайные «наводки»
- людей, которым **уже нечего терять**

🎲 Обычно: **Fast Talk / Persuade / Credit Rating / Luck**

## 2. Форма сделки (d6)

| d6  | Формат                 |
| --- | ---------------------- |
| 1   | Личная встреча         |
| 2   | Через посредника       |
| 3   | Тайник + инструкции    |
| 4   | Обмен без встречи      |
| 5   | Подставная сделка      |
| 6   | Сделка под наблюдением |

## 3. Ассортимент чёрного рынка

### 🔫 Оружие

- нелегальные пистолеты    
- обрезы, старые винтовки
- военное списание
- экзотика (нестабильная)

⚠️ Часто:

- без номеров
- с историей
- с прошлой кровью

### 💣 Боеприпасы и взрывчатка

- патроны сомнительного качества    
- динамит, самоделки
- запалы неизвестного происхождения

🎲 Возможны осечки / преждевременный взрыв

### 📜 Документы

- поддельные удостоверения    
- лицензии
- пропуска    
- архивные справки

❗ Почти всегда **временные**

### 🗝️ Прочее

- яды    
- инструменты взлома
- радиооборудование
- странные предметы «без объяснений»

## 4. Цена сделки

Оплата может быть:

- 💰 деньгами (дороже рынка)    
- 🤝 услугой
- 🧠 информацией
- 👤 чужим именем
- 📦 «доставкой»    

⚠️ Иногда цена раскрывается **после** сделки.

## 5. Проверки и исходы

| Проверка      | Что решает            |
| ------------- | --------------------- |
| Credit Rating | Допуск к товару       |
| Fast Talk     | Условия сделки        |
| Psychology    | Обман / подстава      |
| Luck          | Чистота сделки        |
| Stealth       | Остались ли свидетели |

📉 Провал = не отказ, а **ухудшение последствий**

## 6. Риски чёрного рынка (d10)

| d10 | Последствие                 |
| --- | --------------------------- |
| 1   | Оружие — с уликами          |
| 2   | За сделкой следят           |
| 3   | Посредник исчез             |
| 4   | Цена выросла                |
| 5   | Товар неисправен            |
| 6   | Сделка была ловушкой        |
| 7   | Криминал требует услугу     |
| 8   | Полиция получила наводку    |
| 9   | Заинтересовался культ       |
| 10  | Сделка привлекла **не тех** |

## 7. Репутация

Каждая сделка:

- повышает доступ    
- снижает безопасность
- оставляет след

📌 Через 2–3 сделки:

- персонажей **узнают**    
- им **доверяют меньше**
- цена растёт

## 8. Экстренные сделки

Если «прямо сейчас»:

- меньше проверок    
- больше риска
- почти гарантированные последствия

⏱️ Срочно = плохо.

## 🗂️ Коротко:

**Чёрный рынок не продаёт вещи.  
Он продаёт проблемы — с отсрочкой.**
