# 🧠 ЗДРАВОМЫСЛИЕ (SAN): ОСНОВА

- **Потеря SAN** → при столкновении с ужасом    
- Потери бывают:
    - **0/1, 1/1d6, 1d4/1d10** и т. п.
    - первая цифра — успех проверки
    - вторая — провал

## ⚡ ВРЕМЕННОЕ БЕЗУМИЕ

**Триггер:**

- Потеря **5+ SAN за одну проверку**    

**Эффект:**

- Персонаж теряет контроль **на 1d10 раундов**
- Результат — по таблице временного безумия:
    - бегство
    - ступор
    - истерика
    - агрессия
    - обморок и т.п.

**Если источник ужаса продолжается:**  
→ безумие может **продлиться дольше** (на усмотрение мастера)

## 🕰️ КРАТКОВРЕМЕННОЕ БЕЗУМИЕ

**Триггер:**

- Потеря **5+ SAN за один час**    

**Длительность:**

- **1d10 часов**

**Эффекты:**

- Фобия / мания
- Дезориентация
- Галлюцинации
- Паранойя

📝 Записывается как **психическое расстройство**.

## 🕯️ ДОЛГОВРЕМЕННОЕ БЕЗУМИЕ

**Триггер:**

- Потеря **20% от начального SAN**  
    _(обычно 20 SAN)_    

**Длительность:**

- **1d10 месяцев**

**Эффекты:**

- Тяжёлые расстройства
- Навязчивые идеи
- Изменение личности
- Возможна госпитализация

## ☠️ ПОСТОЯННОЕ БЕЗУМИЕ

**Триггер:**

- **SAN = 0**    

**Итог:**

- Персонаж выведен из игры    
- Стал:
    - безумцем
    - NPC
    - частью мифа
    - пациентом навсегда

## 📉 ВАЖНЫЕ МЕЛОЧИ (которые часто забывают)

- **За одно событие SAN теряется только один раз**    
- SAN **не восстанавливается легко**
- Понимание мифа **уменьшает максимальный SAN**
- Отдых и терапия → **медленное восстановление**

## 🎭 КАК ВЕСТИ БЕЗУМИЕ КРАСИВО

- Не просто «ты боишься» → **конкретное поведение**    
- Фобия = триггер для сцен
- Мания = искушение
- Повторяющиеся мотивы страшнее случайных

## 🧷 КОРОТКАЯ ПАМЯТКА МАСТЕРА

```
5 SAN сразу → временное безумие
5 SAN за час → краткосрочное
20% SAN → долгосрочное
0 SAN → персонаж потерян
```
