# 🕯️ ЧТО ДЕЛАЮТ ВРАГИ ПОСЛЕ ПОРАЖЕНИЯ

Используй, если:

- враг выжил    
- культ разгромлен частично
- угроза отступила, но не исчезла
- игроки ушли, не добив до конца

Брось куб или выбери то, что логично.

## 🧍 ВЫЖИВШИЕ ЛЮДИ

**1d8**

| d8  | Действие                              |
| --- | ------------------------------------- |
| 1   | Исчезают, меняют имена и место        |
| 2   | Сдаются властям (не всё рассказывают) |
| 3   | Ищут защиту у более сильной стороны   |
| 4   | Начинают мстить исподтишка            |
| 5   | Распространяют слухи о следователях   |
| 6   | Пытаются продать информацию           |
| 7   | Спиваются / ломаются психологически   |
| 8   | Пишут дневник / признание (улика!)    |

## 🩸 КУЛЬТЫ И ОРГАНИЗАЦИИ

**1d8**

| d8  | Последствие                     |
| --- | ------------------------------- |
| 1   | Распадаются на мелкие ячейки    |
| 2   | Меняют ритуалы и символику      |
| 3   | Объявляют охоту на виновных     |
| 4   | Уходят в глубокое подполье      |
| 5   | Ищут союз с другим культом      |
| 6   | Делают кого-то козлом отпущения |
| 7   | Ускоряют следующий ритуал       |
| 8   | Считают поражение «знаком»      |

## 🧠 СЛОМЛЕННЫЕ / БЕЗУМНЫЕ

**1d6**

| d6  | Последствие                       |
| --- | --------------------------------- |
| 1   | Полная кататония                  |
| 2   | Навязчивые показания              |
| 3   | Опасные видения                   |
| 4   | Становятся пророками              |
| 5   | Совершают ритуальное самоубийство |
| 6   | Привлекают внимание сущности      |

## 👁️ НЕЧТО НЕЧЕЛОВЕЧЕСКОЕ

⚠️ _Они не проигрывают — они откладывают._

**1d6**

| d6  | Последствие                    |
| --- | ------------------------------ |
| 1   | Исчезает, оставляя след        |
| 2   | Оставляет «якорь»              |
| 3   | Искажает местность             |
| 4   | Помечает выживших              |
| 5   | Возвращается в ином облике     |
| 6   | Становится частью мифа региона |

## 🧷 ЕСЛИ ИГРОКИ УВЕРЕНЫ, ЧТО ПОБЕДИЛИ

Брось **1d6**:

| d6  | Истина                       |
| --- | ---------------------------- |
| 1   | Они действительно победили   |
| 2   | Угроза ослаблена, но жива    |
| 3   | Угроза сменила форму         |
| 4   | Поражение было выгодно врагу |
| 5   | Победа ускорила худшее       |
| 6   | Это была лишь приманка       |

## 🎭 ПАМЯТКА МАСТЕРА

```
Поражение — не конец
Выжившие думают
Культы учатся
Миф терпелив
```

## 💡 Как использовать лучше всего

- Применяй **между сессиями**    
- Записывай последствия в таймлайн
- Пусть игроки **чувствуют инерцию мира**
- Возвращай последствия, когда они уже забыты
