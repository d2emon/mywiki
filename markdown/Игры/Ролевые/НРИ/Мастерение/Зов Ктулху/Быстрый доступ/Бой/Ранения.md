# 🩸 ТАБЛИЦА РАНЕНИЙ И ПОСЛЕДСТВИЙ

Используй:

- при **тяжёлых ранах**    
- при **экстремальном успехе атаки**
- когда хочешь, чтобы бой **запомнился**

Бросай **1d10** или выбирай по ситуации.

## 🧍 ФИЗИЧЕСКИЕ РАНЕНИЯ

| d10 | Ранение              | Последствие                                            |
| --- | -------------------- | ------------------------------------------------------ |
| 1   | Поверхностная рана   | Боль, кровь. −1 к следующему действию                  |
| 2   | Рассечение           | Видимая кровь. Проверка CON или −10% ко всем действиям |
| 3   | Сильный ушиб         | Дезориентация. Следующий ход — с помехой               |
| 4   | Ранение руки         | −20% к атакам / действиям этой рукой                   |
| 5   | Ранение ноги         | Скорость вдвое, бег невозможен                         |
| 6   | Перелом              | Использование конечности невозможно                    |
| 7   | Проникающая рана     | Тяжёлая рана. Проверка CON каждый раунд                |
| 8   | Сильное кровотечение | Теряешь 1 HP/раунд без помощи                          |
| 9   | Обширное повреждение | Потеря сознания при провале CON                        |
| 10  | Ужасающее ранение    | Шрам, инвалидность или ампутация                       |

## 🩸 КРОВОПОТЕРЯ (если уместно)

- Без помощи: **−1 HP каждый раунд**    
- Первая помощь:
    - успех → кровотечение остановлено
    - провал → продолжается
- Экстремальный успех медицины → без последствий

## 🧠 ПСИХОЛОГИЧЕСКИЕ ПОСЛЕДСТВИЯ

Используй, если:

- ранение особенно жестокое    
- бой связан с мифом
- персонаж уже нестабилен

| d6  | Эффект                          |
| --- | ------------------------------- |
| 1   | Паника при виде крови           |
| 2   | Отвращение к оружию             |
| 3   | Кошмары (−1 SAN при плохом сне) |
| 4   | Фиксация на ране                |
| 5   | Вспышки ярости или ступора      |
| 6   | Навязчивое воспоминание         |

## 🦴 ДОЛГОСРОЧНЫЕ ПОСЛЕДСТВИЯ (ПОСЛЕ БОЯ)

Если была **тяжёлая рана**, брось **1d6**:

| d6  | Последствие                   |
| --- | ----------------------------- |
| 1   | Полное восстановление (редко) |
| 2   | Шрам (социальный эффект)      |
| 3   | Хроническая боль (−5–10%)     |
| 4   | Ограничение движения          |
| 5   | Постоянное повреждение        |
| 6   | Инвалидность / протез         |

## ☠️ ЕСЛИ РАНЕНИЕ СМЕРТЕЛЬНО, НО…

Когда персонаж _должен был умереть_, но ты хочешь драму:

- выживает, но:    
    - теряет конечность
    - теряет профессию
    - теряет часть личности
    - становится зависим от лекарств

👉 Цена всегда выше, чем смерть.

## 🧷 ПАМЯТКА МАСТЕРА

```
Ранение = история
Шрам = напоминание
Выжил ≠ отделался
Боль — это давление
```

## 🎭 Как использовать правильно

- Не каждый удар → таблица    
- **Каждая тяжёлая рана → последствие**
- Описывай **ощущения**, не цифры
- Пусть игрок сам выберет, _как это проявляется_
