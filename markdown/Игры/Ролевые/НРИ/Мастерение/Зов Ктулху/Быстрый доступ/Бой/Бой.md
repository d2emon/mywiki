# 🔫 ОБЩАЯ ЛОГИКА БОЯ

- Бой **опасен и короток**    
- Цель — не «выиграть», а **выжить**
- Большинство врагов опасны **даже без высокого урона**

## ⏱️ ПОРЯДОК ХОДОВ

1. Определяется **DEX**    
2. Ходы идут **от большего DEX к меньшему**
3. Действия объявляются **по очереди**

📝 Если хаос — мастер решает, кто раньше.

## 🎯 ДЕЙСТВИЯ В РАУНД

Обычно **одно основное действие**:

- атака    
- выстрел
- бег
- использование предмета
- помощь
- попытка схватить
- **реакция** (уклонение / контратака)

## 🤺 РУКОПАШНЫЙ БОЙ

### Атака

- Проверка **Fighting (Brawl)**    

### Защита (на выбор)

- **Уклонение (Dodge)**
- **Контратака** (тоже Fighting)

👉 Сравниваются уровни успеха:

- обычный
- трудный
- экстремальный

**Побеждает лучший успех.**

## 🔪 УРОН

- Оружие наносит урон по описанию    
- \- **Damage Bonus** (если есть)
- Успешная **контратака** → тоже наносит урон

⚠️ **Экстремальный успех**:

- рукопашный — **максимальный урон**
- огнестрел — **бросок урона дважды**, лучший результат

## 🔫 ОГНЕСТРЕЛЬНОЕ ОРУЖИЕ

- Проверка **Firearms**    
- **Уклоняться от пуль нельзя**, если:
    - цель не предупреждена
    - нет укрытия

### Очереди

- Короткая очередь → бонус к попаданию
- Длинная очередь → несколько целей / больше урона

(Если сомневаешься — **упрощай**.)

## 🛡️ УКРЫТИЯ

- Укрытие уменьшает шанс попасть    
- Может **поглощать урон**
- Дерево ≠ бетон

💡 Игроки, которые ищут укрытия, **живут дольше**.

## 🩸 ТЯЖЁЛЫЕ РАНЫ

**Триггер:**

- Получено **≥ половины HP за один удар**    

**Эффект:**

- Проверка **CON**
- Провал → персонаж падает / теряет сознание
- Успех → продолжает, но серьёзно ранен

## ☠️ СМЕРТЬ

- **HP = 0** → персонаж без сознания    
- Каждый раунд → проверка CON
- Провал → смерть
- Успех → стабилен (временно)

## 🧠 БЕЗУМИЕ В БОЮ (важно!)

- Внезапный ужас → проверка SAN **прямо в бою**    
- Временное безумие может:
    - лишить хода
    - вызвать бегство
    - привести к ошибочным действиям

## 🧷 ЧАСТО ЗАБЫВАЮТ

- Контратака — **опасна, но эффективна**    
- Один выстрел может решить бой
- Враги тоже боятся и бегут
- Убийство ≠ победа (последствия!)

## 📌 ПАМЯТКА МАСТЕРА

```
DEX — порядок
Один удар может всё решить
Укрытие = жизнь
Экстремальный успех = боль
CON решает, жить ли дальше
```

## 🎭 Вести бой по-ктулхиански

- Описывай **хаос и страх**, а не «ход 3»    
- Пусть оружие клинит, руки дрожат
- Последствия важнее цифр
