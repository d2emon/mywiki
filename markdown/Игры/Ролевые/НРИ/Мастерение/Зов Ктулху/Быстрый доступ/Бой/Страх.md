# 😱 ЧТО ДЕЛАЮТ ВРАГИ, КОГДА ИМ СТРАШНО

Используй, когда:

- враг получил тяжёлую рану    
- погиб его союзник
- случилось нечто мифическое
- ситуация вышла из-под контроля

Брось куб или выбери логично.

| --- | ------------------------------------ |
| 1   | Паникует, стреляет вслепую           |
| 2   | Бежит к выходу, бросая всё           |
| 3   | Прячется, зовёт на помощь            |
| 4   | Пытается взять заложника             |
| 5   | Падает на колени, умоляет            |
| 6   | Впадает в ярость, атакует ближайшего |
| 7   | Притворяется мёртвым                 |
| 8   | Сдаётся, если видит шанс выжить      |

## 🎭 ПАМЯТКА МАСТЕРА

```
Страх ломает планы
Враги ошибаются
Они не дерутся до конца
Победа оставляет след
```

## 💡 Как использовать лучше всего

- Не бросай каждый раунд — **только в переломные моменты**
- Пусть враги **реагируют, а не оптимизируются**    
- Страх врага подчёркивает **опасность ситуации**
