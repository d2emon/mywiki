# ⚖️ Таблица правонарушений и наказаний

> ⚠️ **Важно:** наказание определяется не только тяжестью,  
> но и **свидетелями, репутацией, связями и настроением властей**.

## 🟢 Мелкие правонарушения

| Правонарушение                  | Типичное наказание     | Примечания                        |
| ------------------------------- | ---------------------- | --------------------------------- |
| Нарушение общественного порядка | Штраф / предупреждение | Может перерасти при сопротивлении |
| Пьянство в общественном месте   | Ночь в камере          | Повтор → штраф                    |
| Мелкая кража                    | Штраф / учёт           | Репутация страдает                |
| Ложное заявление                | Штраф                  | Иногда — давление полиции         |
| Проникновение без взлома        | Штраф / задержание     | Важен статус объекта              |
| Неповиновение полиции           | Задержание             | Быстро эскалирует                 |
| Драка без оружия                | Штраф / арест          | Кто начал — решает полиция        |

## 🟡 Средние правонарушения

| Правонарушение    | Типичное наказание  | Примечания              |
| ----------------- | ------------------- | ----------------------- |
| Взлом             | Арест / суд         | Залог возможен          |
| Кража со взломом  | Тюрьма              | Улики решают всё        |
| Подлог документов | Суд                 | Часто без залога        |
| Незаконное оружие | Конфискация + арест | Повтор — серьёзно       |
| Нападение         | Суд / тюрьма        | Зависит от вреда        |
| Угроза оружием    | Немедленный арест   | Общественный резонанс   |
| Шантаж            | Суд                 | Часто вскрываются связи |

## 🔴 Тяжкие преступления

| Правонарушение      | Типичное наказание        | Примечания                  |
| ------------------- | ------------------------- | --------------------------- |
| Убийство            | Долгий срок / казнь       | Залог почти невозможен      |
| Попытка убийства    | Тюрьма                    | Даже без жертвы             |
| Похищение           | Тюрьма                    | Высокий приоритет           |
| Поджог              | Тюрьма                    | Особенно общественные места |
| Взрывчатка          | Немедленная изоляция      | Интерес спецслужб           |
| Массовые беспорядки | Жёсткое подавление        | Коллективная вина           |
| Участие в культе    | Психиатрия / исчезновение | Часто неофициально          |

## 🕳️ Особые случаи (Ктулху-специфика)

| Ситуация            | Что происходит                     |
| ------------------- | ---------------------------------- |
| Странные показания  | Игнорируются или трактуются против |
| «Нечто неописуемое» | Объявляется галлюцинацией          |
| Массовая паника     | Назначают виновных                 |
| Слишком много тайн  | Дело закрывают «сверху»            |
| Связь с Мифами      | Исчезновение персонажа             |

## 🗂️ Быстрое правило для Хранителя

- **Мелкое** → неудобства    
- **Среднее** → сюжетный якорь
- **Тяжкое** → слом жизни
- **Мифы** → закона больше нет
