# 💰⏳ Таблица размеров штрафов и сроков (абстрактно)

> Используется, когда **не хочется лезть в юриспруденцию**,  
> но нужно быстро и последовательно определить последствия.

## 1. Шкала тяжести (основа)

| Уровень | Обозначение | Кратко       |
| ------- | ----------- | ------------ |
| 0       | Нарушение   | Формальность |
| 1       | Мелкое      | Неприятно    |
| 2       | Среднее     | Опасно       |
| 3       | Тяжкое      | Ломает жизнь |
| 4       | Критическое | Уничтожает   |

## 2. Штрафы (денежные)

| Уровень | Размер штрафа | Эффект                  |
| ------- | ------------- | ----------------------- |
| 0       | Символический | Запись / предупреждение |
| 1       | Небольшой     | Удар по кошельку        |
| 2       | Значительный  | Финансовый стресс       |
| 3       | Огромный      | Потеря статуса          |
| 4       | Неподъёмный   | Конфискация имущества   |

📌 **Credit Rating**:

- высокий → штраф больше, но больнее по репутации    
- низкий → меньше денег, но строже меры

## 3. Сроки лишения свободы

| Уровень | Срок                | Комментарий       |
| ------- | ------------------- | ----------------- |
| 0       | Задержание          | Часы / ночь       |
| 1       | Краткий             | Дни–недели        |
| 2       | Средний             | Месяцы            |
| 3       | Долгий              | Годы              |
| 4       | Пожизненный / казнь | Персонаж выбывает |

## 4. Условные меры (вместо или дополнительно)

| Уровень | Возможные меры        |
| ------- | --------------------- |
| 1       | Учёт, надзор          |
| 2       | Исправительные работы |
| 2–3     | Запреты, ограничения  |
| 3       | Психиатрия            |
| 4       | Тайная изоляция       |

## 5. Выпуск под залог (абстрактно)

| Уровень | Вероятность  | Условия               |
| ------- | ------------ | --------------------- |
| 0       | Почти всегда | Символический         |
| 1       | Часто        | Деньги или поручитель |
| 2       | Иногда       | Жёсткие условия       |
| 3       | Редко        | Огромный залог        |
| 4       | Никогда      | Без вариантов         |

## 6. Модификаторы (быстро)

Добавь / убери **1 уровень**:

- \+ свидетели        
- \+ общественный резонанс
- \+ рецидив
- \+ связь с Мифами
- \- связи
- \- высокий статус
- \- полезность властям

## 7. Быстрое определение (алгоритм)

1. Определи уровень (0–4)
2. Применяй штраф **или** срок (или оба)
3. Добавь модификаторы
4. Реши вопрос залога
5. Запиши **долгосрочные последствия**

## 🗂️ Коротко:

**Штраф — это боль сейчас.  
Срок — это потеря будущего.  
Уровень определяет масштаб трагедии.**
