# Блокнот мастера

## Общий принцип организации

1. **Быстрый доступ** — то, что нужно за 5–10 секунд за столом.    
2. **Оперативная информация** — текущая кампания, активные НИПы, события.
3. **Архив / мир** — города, организации, карты, таблицы, которые переиспользуются.
4. **Живой документ:** Структура допускает дополнения. Не нужно пытаться заполнить всё заранее. 
5. **Мастерская тайна:** Блокнот должен быть закрыт от глаз игроков.

### Оглавление

Первые страницы блокнота. Здесь вы будете обновлять номера страниц или ссылки на новые разделы по мере их создания. Без этого блокнот станет чёрной дырой.

1. Оглавление
2. Игровой процесс, генерация и экран мастера
3. Таблицы случайной генерации (расширенные)
4. Мир и локации
    1. Города и посёлки
    2. Путеводитель
    3. Важные места
5. Кампания и сюжет
    1. Текущая ситуация
    2. Трекер времени и событий
    3. Календарь
6. Организации и культы
7. Мастерские персонажи (НИПы)
8. Персонажи игроков
9. Архив мифов и странностей

## 🩸  A5 — Оперативный блокнот мастера

> Лежит на столе всегда.  
> Всё, что нужно «прямо сейчас».

**Плюсы**

✅ Очень удобен за столом  
✅ Легко листать одной рукой  
✅ Отлично подходит для НИПов, таймлайна, SAN  
✅ Атмосферно (ощущение личного журнала)

**Минусы**

⚠️ Карты зданий часто мелковаты  
⚠️ Глобальные схемы и планы приходится складывать  
⚠️ Со временем может «разрастись»

### 1️⃣ 🩸 Быстрый доступ — **6 листов**

👉 **Формат:** 5–8 страниц, плотная бумага, ламинированные или всегда в начале.

**Назначение:** не думать, не искать.

1. ***Шпаргалка по правилам:***
    - Правила безумия
    - Восстановления здоровья
    - Вождение автомобиля
    - Взлом замков
    - Сводка боёвки (если используешь)
2. SAN:
    - потери
    - временное / постоянное безумие
2. Фобии и мании (кратко)
3. Архетипы НИПов (1 строка на тип)
4. «Если расследование застопорилось» (6–8 приёмов)

📌 Эти листы можно **вынуть и положить рядом с экраном**.

### 2️⃣ 📊 Таблицы случайной генерации — **10 листов**

Отдельный раздел, который легко пополнять.

**Формат:**

- ***1 таблица = 1 лист**
- Нижняя треть листа — **пустая**

Стартовый минимум (без излишеств):

1. НИП:
    - **внешность**
    - характер
    - **секрет**
    - быстрые имена (2–3 культуры, которые точно будут)
2. **Случайные улики**
    - физические
    - документы / записи
3. Жуткие детали сцены
4. **Сны и видения**
5. **Последствия контакта с мифом**
6. Случайные осложнения
7. Пустая таблица (под импровизации)
8. Случайные уличные события в Аркхэме/в глуши
9. *Локации (заброшенные дома, подвалы, лесные хижины)*
10. *Последствия действий игроков*
11. *Книги (названия, авторы, эффекты при чтении)*
12. *Случайные странные детали (запахи, звуки, находки)*
13. *Таблица «Что пошло не так»*
14. ***Энкаунтеры:*** *Статистика стандартных монстров, которые могут появиться. Быстрые шаблоны для стычек.*

📎 **Совет:**  

- Оставляй **пустые строки в конце каждой таблицы**, чтобы вписывать удачные импровизации — со временем это станет твоим личным генератором.
- Храни таблицы **в алфавитном порядке** или по цвету бумаги.

### 3️⃣ 🗺️ Кампания / текущая арка — **6 листов**

Это _мозг игры_.

- Краткое описание текущей арки 
    - основная идея
    - ключевые события
    - кульминация
    - возможные концовки
- Главная тайна (в 3–5 предложениях)
- Текущая ситуация
    1. _Что происходит на самом деле_
    2. _Во что верят игроки_
    3. _Активные угрозы_
    4. _Культы / сущности (кратко)_ - ???
    5. _Нити, которые игроки бросили_
    6. _Свободный лист «мысли мастера»_

> Это помогает не «переигрывать» тайну и помнить, где игроки находятся по информации.

🧠 Очень помогает не терять фокус и не переусложнять.
✏️ Пиши крупно, с зачёркиваниями — этот раздел должен «жить».

### 4️⃣ ⏳ Время и события — **6 листов**

1. Линия времени (события, если никто не вмешается)
2. Календарь (1 месяц = 1 лист)
    - текущий месяц
    - следующий месяц
3. Фазы луны
4. Ритуалы и дедлайны
5. Последствия (что уже запущено)

🕯️ Для Ктулху это критически важно — **мир не ждёт игроков**.

#### Трекер времени и событий

**Формат:**

- День / дата   
- Событие (явное)
- Скрытые последствия / Действия организаций / Что случится, если игроки не вмешаются
- Ссылка на заметки

Пример:

| **Дата/Время** | **Событие (явное)**                 | **Скрытые последствия / Действия организаций**              | **Ссылка на заметки** |
| -------------- | ----------------------------------- | ----------------------------------------------------------- | --------------------- |
| *25.09.1926*   | _Игроки нашли дневник в библиотеке_ | _Культисты из "Ордена Жёлтого Знака" теперь следят за ними_ | _стр. 15_             |
| 15 марта       | культ завершает подготовку          |                                                             |                       |
| 18 марта       | первое жертвоприношение             |                                                             |                       |
| 21 марта       | ритуал                              |                                                             |                       |

👉 Используй **стрелки, галочки, вычёркивания** — это должен быть «рабочий лист».

#### Календарь

Отмечай:

- фазы луны 🌑
- праздники
- даты ритуалов
- важные сны
- погоду
- Можно использовать реальный календарь 20-х годов

Лучше отдельная страница **на каждый месяц**.

### 5️⃣ 🧠 Игроки — **5 листов**

**Общие заметки по партии:** Кто чем владеет (машина, дом), общие ресурсы, репутация в городе.

По одному на персонажа.

Каждый лист:

- Имя
- *Краткое описание*
- SAN (старт / текущий)
- *Фобии, мании*
- Травмы
- Личные страхи
    - Что персонаж **боится потерять**
- Связи
    - Кого любят, боятся, что скрывают
- Крючки для мастера
    - **Награды и находки:** Что получили (артефакты, контакты, болезни).
    - **Личные цели** игроков для своих персонажей.

⚠️ Это **твои** заметки, не дублируй чарник.
👉 Отмечай **травмы и повторяющиеся темы** — это золото для хоррора.

### 6️⃣ 🧍 НИПы (оперативные) — **10 листов**

- Формат:
    - либо по городам
    - либо по организациям
    - либо по алфавиту
- По 2–3 НИПа на лист

На каждого:

- Имя
- Роль
- *Внешность*
- *Образ*
- Манера речи
- *Мотивация*
- Секрет
- *Что знает (инфодорожка)*.
- *Отношение к игрокам*
- *Связи с другими NPC, организациями, местами*
- *Судьба*
- Статус (жив / мёртв / сломлен)
- *Статистика* (если нужна в бою)*

**Второстепенные NPC (статистика «на лету»):** Список имён и профессий, чтобы быстро выдать копов, библиотекаря, доктора, бродягу.

💡 Эти листы чаще всего переставляются.
💡 Отлично работают **индекc-карточки**, которые можно перекладывать между разделами.
💡 Очень удобно делать **A6-карточки**, вставленные в блокнот.

### 7️⃣ Резерв — **10 чистых листов**

Для:

- экстренных заметок    
- внезапных городов
- внезапных культов
- «ой, это оказалось важно»

### 📦 ИТОГО A5 НА СТАРТ

**≈ 53–55 листов**

Это много, но:

- блокнот не выглядит пустым    
- есть запас
- ничего не надо срочно добавлять после первой же сессии

## 🗺️ A4 — Архив / Штаб расследования (2 скобы)

> 📎 Лежит рядом или достаётся по необходимости как досье.

**Плюсы**

✅ Идеален для карт и чертежей  
✅ Удобно хранить вырезки, распечатки  
✅ Хорошо подходит для городов и организаций  
✅ Можно разворачивать на столе

**Минусы**

⚠️ Менее мобильный  
⚠️ Неудобен для быстрых заметок  
⚠️ Сложнее листать во время напряжённых сцен

💡 **Карты зданий** лучше держать:

- в сложенном виде
- или в отдельном A4-файле

### 1️⃣ 🏙️ Города и посёлки — **6 листов**

**1 населённый пункт = 2 листа**

⚠️ Очень важно:  
**оставляй минимум 30–40% страницы пустой** для дописывания по ходу игры.

На старт:

- 1 основной город (2 листа)    
- 1–2 второстепенных (по 1–2 листа)

Шаблон города:

- Общая информвция
    - Название
    - **Атмосфера**
        - настроение
        - запахи
        - стиль
    - ключевые районы
    - население
 - **Путеводитель:** Список гостиниц, ресторанов, больниц, магазинов с именами и характерами владельцев (для справки)
    - **Важные места (подподсекция):** Каждому месту (библиотека, полицейский участок, музей, бар, заброшенный особняк) — отдельная страница или карточка.
        - **Описание** (внешнее/внутреннее).
        - **Ключевые NPC** здесь.
        - **Подсказки/улик**и, которые можно найти.
        - **Опасности/ловушки**.
        - **Карта/план этажа** (схематичный рисунок).
    - **Важные НИПы**
    - **Тайны / Слухи**
- Карта:
    - Общая схема.

📌 Совет:  
Клади **карты города** в файл сразу за этими листами.

### 2️⃣ 🏛️ Организации и культы — **4 листа**

- 2–3 организации на старт    
- 1 организация = 1–2 листа

**Шаблон организации:**

- Название
- Внешний образ
- Публичная цель
- Скрытая цель
- Лидер(ы)
- Методы
- Ресурсы
- Базы
- Символы
- Текущие планы
- Связи
- Текущий статус (активна / разгромлена / затаилась)

🩸 Отмечай:

- сорванные ритуалы    
- статус
- потери
- ошибки
- следы
- компрометирующие факты

👉 Даже «безобидные» газеты и университеты стоит сюда вносить — они часто возвращаются.

### 3️⃣ 🏙️ Важные места — **4 листа**

- заброшенные дома    
- особняки    
- лаборатории
- храмы
- пещеры

Каждое:

- описание
- атмосфера
- секреты    
- карта

### 4️⃣ 🏙️ Карты зданий — **6–10 листов**

- особняк    
- склад
- подвал
- больница
- библиотека

📎 Лучше:

- хранить в **кармашках**
- или как вкладыши
- или в цифровом виде с быстрым доступом

### 5️⃣ 📚 Архив мифов — **4 листа**

- книги    
- заклинания
- сущности
- сны
- символы
- повторяющиеся мотивы

Формат — кратко, фрагментарно, как будто записи сумасшедшего.  
Лучше _намёки_, чем полные описания.

### 6️⃣ Резерв — **10 чистых листов**

### 📦 ИТОГО A4 НА СТАРТ

**≈ 34–38 листов**

## **Технические рекомендации:**

- **Разделители с кармашками:** Для карт, раздаточных материалов, рисунков.   
- **Перфорированные блоки бумаги разной линейки:** в клетку для карт, чистые для заметок, в линейку для текста.
- **Карточки 10x15 см:** Идеальны для NPC и локаций. Можно быстро перекладывать, группировать.
- **Стикеры-флажки и маркеры:** Для быстрого поиска.
- **Карандаш и ластик:** Всё меняется в процессе игры.

### Цветовая кодировка

- 🔴 Красный — мифы, культы, SAN    
- 🔵 Синий — города, люди
- 🟢 Зелёный — природа, изоляция
- ⚫ Чёрный — истина, финалы, тайны

Можно:

- цветные разделители
- маркеры
- точки на углах страниц

## **Советы по ведению:**

### Во время сессии

- Делай быстрые заметки
- Пиши **ключевые слова**
- Стрелки, знаки вопроса, подчёркивания
- Не бойся грязи — это часть атмосферы

### После сессии (10–15 минут)

- Перенести заметки
- Добавить 1–2 новых НИПа
- Обновить таймлайн
- Записать идеи на будущее
