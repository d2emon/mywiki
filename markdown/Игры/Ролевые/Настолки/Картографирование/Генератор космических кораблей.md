# Находка: генератор космических кораблей

Одна из проблем настольных ролевых игр в космическом антураже — создание оригинальных космических кораблей. Порой персонажи игроков сталкиваются с торговцами или пиратами, и ведущему нужно показать, что из себя представляет их судно. Подобную проблему призван решить [генератор ShapeWright.com](http://ship.shapewright.com/).

На вкладке Ship сайт создаёт из схематичных блоков вариацию судна — большого, маленького, с разными палубами и расположением двигателей. Нужно только вбить название, и тогда генератор покажет очередную схему, которую можно сохранить в формате VML. Да и работает только с примитивными блоками — никаких экзотических конструкций кораблей пришельцев а-ля «каракатица в космосе» он не создаст.

Помимо космических кораблей shapeWright умеет создавать 3D-модели колец. Для них пользователь сам задаёт параметры при помощи ползунков.

[![](https://i3.wp.com/www.mirf.ru/backend/wp-content/uploads/2019/01/c30048cd240148b4a998a8f8ad9b33e7.png)](https://www.mirf.ru/backend/wp-content/uploads/2019/01/c30048cd240148b4a998a8f8ad9b33e7.png)

На третьей вкладке shapeWright позволяет сгенерировать экзотическую форму существа в духе Spore — допустим, обитателя другой планеты. Получаются забавные организмы.
