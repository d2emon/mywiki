# Бой на бутылках

**Инвентарь:** Стеклянные бутылки.

**Суть:** Участники собирают бутылки, после чего бьются ими, как яйцами на пасху.

## Места проведения:

* Подальше от ненужных глаз.
* Там, где битые стёкла не мешали бы никому.
* Идеально для для этой роли подходит свалка, с её сотнями бутылок, но имеется риск нарваться на враждебных крипов, для которых орудия игры являются орудиями заработка.

## Чит: 

GODMODE активируется по нахождению бутыля от шампусика, ибо степень сопротивления ему со стороны других участников баталий КРАЙНЕ МАЛА.
