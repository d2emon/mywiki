# Поезд «Москва — Нижний Новгород»

1. Снег еще не растаял, он лежит на северном склоне. Значит, поезд движется с запада на восток, то есть из Москвы в Нижний Новгород.
2. Время года — весна: снег тает. Месяц — апрель: у девочки в руках цветущая верба.
3. Девочка держит в руках посох, а рядом с ней собака — значит, скорее всего, она пастушка.
