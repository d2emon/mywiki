## Караваны

### Из города Госпитальер в Горький Лес

Из республики Госпитальеров на север в Южногорье. Из Южногорья на север в Привок. Из Привока на север в Глубар. Из Глубара на север в Перевал. Из перевала на запад в Красные Горы. Из Красных Гор через Седьмой Перевал и Кривой Мост в Железные Земли. Из Железных Земель через Шахтерский Мост в Дикие Леса

### Из Майского Леса в город Эскобаз

Из Красных Гор на юго-запад в Первач. Из Первача на запад по границе Железных Земель и Дурха в Гайш. Из Гайша ерез крепость "Полевую" в Джубал.

### Из города Волк в крепость "Железную"

Из Лазурного Берега на северо-запад в Друч. Из Друча на северо-запад в Малдер. Из Малдера на северо-запад в Стокхейм. Из Стойхейма на запад в Перевал. Из Перевала на запад в Красные Горы. Из Красных Гор через Седьмой Перевал и Кривой Мост в Железные Земли.

### Из Майского Леса в крепость "Алакс"

Из Красных Гор через Седьмой Перевал и Кривой Мост в Железные Земли. Из Железных Земель через Шахтерский Мост в Дикие Леса. Из Диких Лесов в крепость "Алакс".

### Из города Косарь в крепость "Кулак"

Из Косари на юго-восток в Вураг. Из Вурага на восток в Лутавию. Из Лутавии на север в Ми-Го. Из Ми-Го на север в Тальмар.
