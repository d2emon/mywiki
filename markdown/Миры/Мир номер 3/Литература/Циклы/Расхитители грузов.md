# Расхитители грузов

Серия книг о Джеке Периле, сыне астронавта Перила из ["Паники"](./Паника.md).
Джек возглавляет различные операции против особо крупных грабителей.
Серия выросла из новеллизации фильма "Расхитители грузов".

## 92

* Lode Runner       Боевик
  Книга [Brøderbund Software, Inc.]().
  Новеллизация фильма.
  Каперы империи Бунгелингов ограбили корабль с драгоценностями. Логово каперов охраняется при помощи роботов.
  В логово проникает Джек Перил чтобы вернуть драгоценности.

## 98

* Diamond Dash      Боевик
  Книга Игната Софтека.
  В книге не участвует Джек Перил.
  Командос похищает сокровища у империи Бунгелингов.

## 99

* Lode Runner: The Legend Returns   Боевик
  Книга [Sierra On-Line, Inc.]().
  Джек Перил вновь проводит операцию по возвращению драгоценностей.
  На этот раз он противостоит Безумным Монахам из культа каннибалов.
* Gold Runner       Боевик
  Книга Тома Нивински.
  Вольное продолжение приключений команды Джека Перила.

## 100

* Lode Runner On-Line: The Mad Monks' Revenge   Боевик
  Книга [Sierra On-Line, Inc.]().
  Джек Перил вновь противостоит империи Бунгелингов и Безумным Монахам.

## 101

* Scavenger         Боевик
  Автор неизвестен.
  Сборник рассказов о Джеке Периле.

## 103

* Lode Runner 2         Боевик
  Книга [Shanghai UBIsoft Computer Software Co., Ltd.]() и [GT Interactive Software Corp.]().
  Джек Перилл и его напарница Джейн противостоят банде грабителей банков.

## 111

* Lode Runner           Боевик
  Книга Зухеля Ксепа.
  Неофициальная новеллизация легендарного фильма.

## 122

* Lode Runner: Legacy   Космический боевик
  Книга [Tozai, Inc.]().
  Внук Джека Перилла учится в космической академии и попадает в неприятности с пиратами.
