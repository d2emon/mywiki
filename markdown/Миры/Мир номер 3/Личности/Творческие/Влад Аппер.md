# Влад Аппер (Север)

Влад Аппер один из родоначальников Северного Кино. Почти все Северяне отталкиваются в своем творчестве от пьес-скетчей Аппера.

Аппер режиссер в первую очередь театральный, в кино пришел только в 80-х
