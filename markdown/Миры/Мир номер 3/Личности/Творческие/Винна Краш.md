# Винна Краш

Кинокритик. Телеведущий. В качестве режиссёра снял ряд фильмов.

## 94

* Egghead               Фентези
  Эггхед бежит из темницы.
* Whole New Ball Game   Космоопера
  Добыча минералов при помощи новой технологии.

## 95

* Doomskulle            Фентези
  Фильм вдохновлён "Сейбервульфом".
  Приключенец отправляется в проклятый лес на поиски артефакта.
* Egghead 2             Фентези
  Эггхед пытается спасти друзей из темницы.
* Master Blaster        Космический боевик
  Экипаж космического корабля разведывает дальний космос.

## 96

* Dizzy 3 and a Half    Фентези
  Короткометражный фильм.
  Предистория четвертой части Диззи.
* Master Brain          Детектив
  Детектив с камео многих знаковых персонажей эпохи.
