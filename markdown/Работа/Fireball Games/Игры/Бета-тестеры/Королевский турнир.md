# Королевский турнир

**"Королевский турнир"** — симулятор конного турнира компании **"Самара Софт"**.

- Детально проработана физика верховой езды.
- Для начала участия в турнирах нужно сорвать копьем кольцо с ремешка.
- На старте есть небольшой капитал. Нужно приобрести:
    - Комплект турнирного доспеха
    - Запасные копья
    - Упряжь
    - Расходы на геральдику
    - Расходы на знамена
    - Расходы на вымпелы
    - Взносы за аренду палатки
    - Взносы за фураж
    - Взносы в призовой фонд
- Можно заработать деньги на большой дороге
    - Нужно учитывать взятки
- Главный турнир - королевский
    - В финале появится Безымянный Рыцарь
        - На самом деле - король
- Происки конкурентов
    - Подпругу могут развязать
    - Коню может не хватить корма
    - Родословная может быть задержана мэрией
    - Могут быть наемные убийцы на турнире
- Нападают бандиты
    - Может быть монах-провокатор
