# Филамент

## **1. Визуализация и роль игрока**

### **Персонаж/Аватар**:

- **Форма**: Игрок воплощен в **«Ковчег-Сингулярность»** — корабль/существо из плазмы и тёмной материи, способное менять размер и плотность.    
    - Внешний вид: Напоминает **межзвёздный кальмар** с щупальцами-гравитационными антеннами, сканирующими пространство.
    - Ядро: Мини-черная дыра, питающаяся межгалактическим газом.
- **Логика**: Вы — «посредник» между масштабами, перераспределяющий материю и энергию для баланса структур.

### **Окружение**:

- **В филаментах**:    
    - **Галактические реки**: Потоки спиральных и эллиптических галактик, движущихся вдоль нитей (как светящиеся жемчужины на невидимых струнах).
    - **Мост Столкновения**: Места, где сталкиваются галактические скопления, создавая огненные дуги из новых звёзд.
- **В войдах**:
    - **Оазисы пустоты**: Одинокие "голубые бродячие галактики", оторванные от скоплений.
    - **Тени Архитекторов**: Артефакты в виде черных кубов, парящих в центре войдов.

## **2. Генерация мира**

### **Алгоритм**:

- **Основа**:    
    - Для филаментов: **N-тел симуляция** (упрощённая) для распределения галактик под действием гравитации.
    - Для войдов: **Пойнт-процесс с пуассоновским распределением** редких галактик.
    - Дополнение: **Пользовательские seed-параметры** из предыдущего масштаба (например, если игрок сжал филамент на уровне LSS, здесь будет больше карликовых галактик).

### **Параметры**:

- **«Галактическое разнообразие»**: Типы галактик (спиральные, эллиптические, неправильные), их возраст и активность ядер.    
- **«Газовый фон»**: Количество межгалактического газа, влияющего на образование звёзд.

## **3. Основные механики**

#### **Перемещение**:

- **Галактические прыжки**: Использование гравитационных линз от скоплений для мгновенных перемещений (аналог прыжков в _Mass Effect_).
- **Потоки темной материи**: Движение вдоль невидимых рек, ускоряющее полёт, но требующее сканирования.

### **Взаимодействие**:

- **Управление галактиками**:    
    - **Слияние галактик**: Запуск столкновений для создания эллиптических галактик с квазарами.
    - **Зарождение жизни**: "Засев" молодых галактик органическими молекулами через межзвёздные кометы.
- **Войды**:
    - **Стабилизация одиноких галактик**: Помощь в формировании звёзд при нехватке газа.
    - **Колонизация войдов**: Создание искусственных скоплений из тёмной материи для притяжения блуждающих галактик.

### **Ресурсы**:

- **Межгалактический газ** — используется для подпитки звёздообразования.    
- **Квантовая пена** (из предыдущего масштаба) — для создания червоточин.
- **Энергия квазаров** — для активации артефактов Архитекторов.

## **4. Игровой процесс**

### **Цели**:

- **Восстановите "Великий Аттрактор"** — таинственную гравитационную аномалию, тянущую местные галактики.    
- **Остановите "Войд-Пламя"** — войд, где тёмная энергия ускоряется, угрожая разорвать филаменты.
- **Квесты**:
    - Найди "Галактику-Сфинкс" — мегаструктуру, созданную древней расой, с головоломками в стиле _Outer Wilds_.
    - Уничтожьте "Черный Рой" — скопление блуждающих черных дыр, возникших из-за ошибок игрока на уровне LSS.

### **Стратегия**:

- **Дипломатия с цивилизациями**:    
    - Контакт с **Сетью Нексионов** (разумные галактические кластеры) для обмена технологиями.
    - Конфликты с **Харвестерами Энергии** — расами, выкачивающими энергию из квазаров.

## **5. Визуальные эффекты и интерфейс**

- **HUD**:    
    - **Карта гравитационных аномалий** — 3D-голограмма с тепловой картой масс.
    - **Спектрограф** — анализ состава галактик (металличность, наличие жизни).
- **Эффекты**:
    - **Галактические танец**: Замедленная съемка слияния галактик с волнами звёздного ветра.
    - **Войд-эхо**: Звуковые волны от одиноких галактик, визуализированные как рябь в пространстве.

## **6. Связь с другими масштабами**

- **Вниз**: Погружение в галактику открывает доступ к звёздным системам (масштаб килопарсеков).    
- **Вверх**: Создание сверхскопления активирует возврат к уровню космической паутины.
- **Параллельно**: Найденные в войдах артефакты позволяют "просочиться" в квантовый масштаб через сингулярности.

## **7. Пример игровой сессии**

1. Игрок входит в филамент, обнаруживая цепь из 12 стареющих спиральных галактик.    
2. Используя межгалактический газ, он "подкармливает" их, запуская вспышки звёздообразования.
3. Одна из галактик оказывается носителем сигнала Нексионов — игрок вступает в переговоры, получая доступ к чертежам гравитационного двигателя.
4. Внезапно активируется "Войд-Пламя" — игрок перенаправляет часть газа из филамента, чтобы создать барьер из тёмной материи.
5. В благодарность Нексионы показывают координаты "Галактики-Сфинкс", где игрок решает квантовую головоломку, открывая портал в масштаб планетарных систем.

## **8. Технические нюансы**

- **Оптимизация**:    
    - Галактики вне текущего скопления рендерятся как спрайты с LOD.
    - Физика упрощается до Newtonian N-body с предсказуемыми орбитами.
- **Сохранение**:  
    Состояние каждой галактики хранится в виде seed + модификаторов (например, "молодая", "с квазаром").
