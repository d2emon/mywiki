# Группа галактик

## **1. Визуализация и роль игрока**

### **Персонаж/Аватар**:

- **Форма**: Игрок управляет **«Экзо-Кораблем»** — трансформирующимся звездолётом, созданным из **метаматериалов Архитекторов**.  
  - **Режимы**:  
    - **Сканирующий зонд** (компактная форма для исследования рукавов).  
    - **Боевой Левиафан** (гигантский корабль-крепость для битв с космическими чудовищами).  
  - **Внешний вид**: Футуристический дизайн с адаптивной броней, светящейся в ритме ближайших звёзд.  

### **Окружение**:

- **Спиральные рукава**:  
  - **Звёздные колыбели**: Облака пыли и газа, рождающие звёзды (визуал: неоновые туманности с протопланетными дисками).  
  - **Чёрные рынки**: Плавающие станции контрабандистов на астероидах.  
- **Галактическое ядро**:  
  - **Квазар-тюрьма**: Сверхмассивная чёрная дыра, окружённая клетками для космических существ.  
  - **Руины Древних**: Мегаструктуры, оставшиеся от расы, слившейся с тёмной материей.  

## **2. Генерация мира**

### **Алгоритм**:

- **Основа**:  
  - **Звёздные карты**: Процедурная генерация на основе **фрактальных алгоритмов** (повторение паттернов спиральных рукавов).  
  - **Динамические события**:  
    - Взрывы сверхновых, формирование планетных систем.  
    - Миграция космических существ через **межзвёздные миграционные коридоры**.  
- **Параметры**:  
  - **«Температура рукава»**: Определяет активность звёздообразования.  
  - **«Уровень угрозы»**: Частота появления чудовищ и пиратов.

## **3. Основные механики**

### **Перемещение**:

- **Гипердвигатель**: Прыжки между звёздными системами с риском привлечь внимание чудовищ.  
- **Гравитационные рогатки**: Использование массивных объектов (нейтронных звёзд, чёрных дыр) для ускорения.  

### **Взаимодействие**:

- **Бой с чудовищами**:  
  - **Космический Кракен**: Существо, питающееся звёздной плазмой. Слабые точки — глаза-квазары.  
  - **Вирусные Рояры**: Механические паразиты, взламывающие системы корабля.  
- **Исследование**:  
  - Сбор **звёздной пыли** для ремонта корабля.  
  - Активация **древних маяков**, открывающих порталы в квантовый масштаб.  

### **Ресурсы**:  

  - **Экзотическая материя** — для создания червоточин.  
  - **Кристаллы сингулярности** — добываются в аккреционных дисках чёрных дыр.  
  - **Данные Предтеч** — артефакты с технологиями Архитекторов.  

## **4. Игровой процесс**

### **Цели**:

- **Очистите рукав от Червей Пустоты**: Гигантские существа, пожирающие звёзды.  
- **Восстановите Галактический Кодекс**: Соберите фрагменты древнего алгоритма, управляющего эволюцией галактики.  
- **Квесты**:  
  - **«Танец с Немезидой»**: Уведите блуждающую нейтронную звезду от обитаемой системы.  
  - **«Сердце Левиафана»**: Уничтожьте чудовище, используя его же энергию, чтобы зарядить гипердвигатель.  

### **Стратегия**:  

- **Адаптация корабля**:  
  - Установка **плазменных гарпунов** для боя с существами.  
  - Модернизация сканеров для обнаружения скрытых червоточин.  
- **Дипломатия**:  
  - Переговоры с **Культом Звёздных Китов** — фанатиками, поклоняющимися чудовищам.  

## **5. Визуальные эффекты и интерфейс**

- **HUD**:  
  - **Карта угроз**: 3D-радар, показывающий движение существ и аномалий.  
  - **Анализатор существ**: Биомеханические схемы чудовищ с указанием уязвимостей.  
- **Эффекты**:  
  - **Световые искажения** при приближении к чёрной дыре.  
  - **Квантовые вспышки** при активации древних технологий.  

## **6. Связь с другими масштабами**

- **Вниз**: Посещение **звёздной системы** (масштаб астрономических единиц) для добычи ресурсов или спасения цивилизаций.  
- **Вверх**: Создание стабильного **гиперканала** в рукаве открывает путь к уровню скоплений галактик.  
- **Побочные эффекты**: Уничтожение чудовища в галактике может вызвать вспышку звёздообразования, влияющую на филаменты.  

## **7. Пример игровой сессии**

1. Игрок исследует спиральный рукав, обнаруживая аномалию — **«Сонный Квазар»**, излучающий странные сигналы.  
2. При приближении активируется **Рой Вирусных Рояров** — игрок переключается на боевой режим, используя импульсные лучи.  
3. После боя сканирование квазара открывает координаты **«Гнезда Кракена»** — игрок готовит гарпуны с экзотической материей.  
4. В битве с Кракеном игрок повреждает его глаза-квазары, заставляя существо отступить в чёрную дыру.  
5. Награда — **Ядро Кракена**, дающее доступ к чертежу **«Гравитационной сети»** для управления рукавами галактики.
